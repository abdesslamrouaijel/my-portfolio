# Portfolio website

A personal portfolio website presenting projects, skills, and background in AI, data science, and robotics.

## Repository guide

- `index.html` — page structure, content, and inline browser interactions.
- `stylesheet.css` — styling and responsive presentation.
- `main.js` — navigation and animated headline behavior.
- Image files in the repository root provide the visuals used by the site.

## Viewing locally

Open `index.html` in a browser. The page references external resources for icons and the animated headline, so an internet connection is needed for those assets.

## Path dependencies

The HTML and stylesheet refer to local files by relative path. Keep their existing names and locations unless all references are updated and the site is checked afterwards.
